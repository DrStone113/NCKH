- User wanted the AI chatbot to proactively pull information via Tools (like today's meals, profile, calories) without making excuses.
- User requested output formats that the Frontend (Flutter) can easily handle, specifically leveraging the `StructuredResponse` JSON mapping in `wger_models.dart`.

- User requested real-time word-by-word streaming to display answers immediately as they are generated by the LLM.
